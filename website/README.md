# Product website

Static HTML/CSS/JS in this folder. No vault. No npm build.

Local: `npx --yes serve website -l 5180`

Host (Vercel, Netlify, Cloudflare Pages): see [docs/HOSTING.md](../docs/HOSTING.md).

Live demo on the page is frontend-only (YouTube IFrame + preloaded topics/marks/shots/sources). The large **App** section is an independent in-phone preview (own player, Marks, Shots, Bio, Sources).
