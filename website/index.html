How it works

Local-first from captions to answers — no VideoSearch account.

Captions

Native timedtext via YouTube Innertube (manual preferred over ASR).

Chunk & embed

Sentence-aware windows + MiniLM in WASM, stored in IndexedDB.

Search & chat

Hybrid retrieve for moments; RAG context for Chat answers.

Jump

Reliable player seek from times, topics, sources, or live lines.

Get started

Install the Chrome extension

Load unpacked from the open-source build. Works with Chrome today.

  1. 1
    Clone & build Produce the dist/ folder from the repo.
    # terminal
    git clone https://github.com/Kadiwalhussain/VideoSearch.git
    cd VideoSearch && npm install && npm run build
  2. 2
    Open Chrome extensions Go to chrome://extensions → enable Developer mode.
  3. 3
    Load unpacked Select the project’s dist/ directory — not the repo root.
  4. 4
    Open YouTube Click the mint pill. Add a Groq key in ⚙ for full Chat RAG.

Privacy

Local-first by design

Transcripts and embeddings stay in the browser. You control optional LLM calls.

On-device index

Captions chunked and embedded with MiniLM in WASM. Indexes live in IndexedDB.

No product account

No login, no sync server, no analytics backend in the extension pipeline.

Optional AI only

Chat and smart topics use your key when enabled. Search works without one.

FAQ

Questions

Does it work offline?

After indexing, search, local topics, live transcript, and seeks work offline. Chat needs network for the LLM.

Do I need an API key?

Not for search. For Chat RAG, paste an OpenAI-compatible key in Settings (Groq default endpoint).
