FAQ

Questions

Do I have to leave for YouTube to rewatch a mark?

No. On Android or iPhone, tap a mark or shot — the in-app player seeks. YouTube is only if you choose the open icon.

What is extracted automatically?

Topics first from closed captions, then marks from the transcript. Shots come from key CC beats. Sources come from URLs spoken in captions and links in the bio.

How do sources get into Studio?

From the transcript and from Sync bio. Spoken links plus Drive / PPT / PDF / GitHub in the description all land in Sources.

Do I need an API key?

Not for search, marks, shots, or bio sync. Chat RAG uses an optional OpenAI-compatible key (Groq by default).

Is the player ad-free?

It is YouTube’s official in-app player. We keep you inside VideoSearch; we do not bypass YouTube ads.
